**Empirica**, nöroplastisiteyi tetiklemek ve bilişsel performansı maksimize etmek için tasarlanmış modern bir zihin antrenmanı platformudur. Mantık, odak, çalışma belleği, yön refleksi, zihinsel rotasyon, bölünmüş dikkat ve strateji disiplinlerinde **21 bilimsel egzersiz modu** ve **420 aşamalı seviye** sunar.

## 🌟 Öne Çıkan Özellikler

- **♟️ FIDE Kurallı Gerçek Satranç Masası:** Çoban Matı'ndan Morphy'nin Opera Matı'na, boğmaca, açmaz, şiş ve saptırma taktiklerini içeren 20 gerçek taktik bulmaca ve serbest analiz modu.
- **🧩 Neural Maze (Mantık Labirenti):** Sokoban blok itme, sürtünmesiz buz kayması, lazer kilitleri, kuantum portalları ve basınç plakaları içeren 20 karmaşık uzamsal rota seviyesi.
- **⚡ NeuroShift & Stroop Egzersizleri:** Sürekli değişen kurallar, renk-anlam çelişkileri ve refleks kombo çarpanları.
- **🎯 Bilimsel Dual N-Back & MOT Takibi:** NASA standartlarında çoklu nesne takibi (Radar Tracking) ve ikili çalışma belleği testleri.
- **🔥 Seri & Dondurma Mekaniği (Streak Freeze):** Her gün devam eden antrenman serileri ve kaçırılan günleri telafi eden dondurma sistemi.
- **🧭 Nöro-Performans Koçu & Sosyal Skor:** Egzersiz verilerine göre analiz sunan koçluk modülü ve arkadaş listeli liderlik tablosu.
- **🛡️ Error Boundary & Tam Kalıcılık:** Zustand ve LocalStorage destekli, sıfır veri kaybı sağlayan dayanıklı durum yönetimi.

## 🚀 Kurulum & Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları takip edin:

```bash
# 1. Depoyu klonlayın
git clone https://github.com/Arda-ERDEM/Empirica.git
cd Empirica

# 2. Bağımlılıkları yükleyin
npm install

# 3. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine giderek Empirica'yı deneyimleyebilirsiniz.

### 📦 Üretim Derlemesi (Production Build)

```bash
# Projeyi optimize edilmiş üretim modunda derleyin
npm run build

# Üretim sunucusunu başlatın
npm run start
```

│   │   ├── NeuroShiftArcade.tsx  # NeuroShift Arcade motoru
│   │   ├── PatternMatrixGame.tsx # Hafıza matrisi motoru
│   │   ├── FocusTrackerGame.tsx  # Dikkat takip motoru

│   │   ├── SpeedMathGame.tsx     # Hızlı matematik motoru

│   └── social/                   # Liderlik tablosu ve arkadaşlık
